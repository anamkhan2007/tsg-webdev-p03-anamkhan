# Meridian - Multi-Page Blog Website

A three-page static blog website built with **HTML5** and **CSS3 (Flexbox & Grid)**, designed as an editorial journal on web craft and design. Submitted for The Sky Gen - Web Development, Project 03 (Beginner).

---

## Live Deploy

- **GitHub Repository:** `https://github.com/anamkhan/tsg-webdev-p03-anamkhan`
- **Live Website:** `https://tsg-webdev-p03-anamkhan.netlify.app`

> Replace the placeholders above with your real links after deploying.

---

## Pages

| # | File | Purpose |
|---|------|---------|
| 1 | `index.html` | Home - hero, intro, three pillars, featured essay, post grid, newsletter CTA |
| 2 | `blog.html` | Journal - full archive of post cards (image, title, date, preview) with a sidebar |
| 3 | `contact.html` | Contact - styled, validated form + contact details and social links |

All three pages share the **same navigation bar, footer and single stylesheet**, and the current page is highlighted in the navigation with an active indicator.

## Required Features (per brief Section 02)

- [x] Three pages - `index.html`, `blog.html` and `contact.html`, all linked through a shared navigation bar
- [x] Shared stylesheet - one CSS file (`css/style.css`) used by all three pages, no repeated styles
- [x] Home page with a hero section, a short intro and links to the blog
- [x] Blog page with post cards, each with an image, title, date and short preview text
- [x] Contact page with a styled form and contact details
- [x] Consistent header and footer on every page
- [x] Active page indicator in the navigation showing which page you are on
- [x] Responsive layout - readable on mobile with no horizontal scrolling
- [x] Organised folders - separate folders for CSS and images

## Technologies

- HTML5
- CSS3 (Flexbox & Grid, custom properties, clamp-based fluid type)
- Font Awesome 6.5.2 (icon set, via cdnjs CDN)
- Google Fonts - Playfair Display, Cormorant Garamond, Inter
- Vanilla JavaScript (mobile menu, scroll reveal, form validation)
- Royalty-free photography from Unsplash
